# SafeVision

Sistema híbrido de visão computacional em Python para detecção de EPIs.

## Estrutura do Projeto

- `app/`: Aplicação Streamlit.
- `core/`: Lógica central de processamento e detecção.
- `models/`: Implementações dos modelos de detecção.
- `evaluation/`: Scripts e métricas de avaliação.
- `notebooks/`: Notebooks de treinamento e experimentação.
- `configs/`: Configurações dos modelos.
- `results/`: Resultados das detecções.
- `pesos/`: Pesos dos modelos treinados.
